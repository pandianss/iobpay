# IOB Pay — promotional page

A single self-contained HTML page promoting **IOB Pay**, the Indian Overseas Bank
online payment aggregator platform for institutions, businesses and organisations.

Published with GitHub Pages: <https://pandianss.github.io/iobpay/>

## Contents

- `index.html` — the whole page. No build step, no external assets: fonts come from
  Google Fonts, every illustration is inline SVG, and the IOB logo is embedded as a
  data URI.

## Sections

Hero · why IOB Pay · payment modes · how the money moves (T+1 settlement) ·
who benefits · sector use cases (education, healthcare, hotels & travel, e-commerce,
government, trusts, associations) · standalone vs API integration · onboarding steps ·
transaction charges by merchant category · FAQ · contact.

Promotional material, not a contractual offer. The charge schedule shown is the one
valid up to 31.03.2025 and is exclusive of applicable taxes; final commercials and
terms are as per the merchant agreement executed with Indian Overseas Bank.
